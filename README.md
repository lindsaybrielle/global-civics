# Global Civics

Free tools that help people take part in civic life.

| Project | What it does |
|---|---|
| [Ballot Abroad](ballot-abroad/) | Helps Americans living abroad register, see every race on their ballot, and share their 2026 midterm picks as Instagram/WhatsApp story images. |

## Hosting

Every project is a static site, so you can host the whole repo free on GitHub Pages: go to **Settings → Pages**, choose the `main` branch and the `/ (root)` folder. Each project then appears at `https://<user>.github.io/global-civics/<project>/`.
