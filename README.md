# Global Civics

Free tools that help people take part in civic life.

| Project | What it does |
|---|---|
| **Ballot Abroad** · [open the app](https://lindsaybrielle.github.io/global-civics/ballot-abroad/) · [code](ballot-abroad) | Helps Americans living abroad register, see every race on their ballot, and share their 2026 midterm picks as Instagram/WhatsApp story images. |

## Hosting

Every project is a static site, so you can host the whole repo free on GitHub Pages: go to **Settings → Pages**, choose the `main` branch and the `/ (root)` folder. Each project then appears at `https://lindsaybrielle.github.io/global-civics/<project>/`. The "open the app" links only work once Pages is switched on; until then they return a 404.
